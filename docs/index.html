jsonkit

Agentic-first JSON manipulation service. Format, minify, validate, query, extract, flatten, merge, diff, sort, filter, transform, and analyze JSON data.

Go Single Binary Zero Config Plain Text API MCP Ready
View on GitHub Quick Start

Quick Start

make build
./jsonkit

# or with custom port
./jsonkit -port 9000

Principles

The Agent IS the Interface

No UI, no SDK. The AI agent is the user. The API is the product.

Plain Text by Default

One labeled, grepable line per record. JSON available via ?format=json.

Instructive Errors

Every 4xx response includes a hint telling the agent what to do next.

Self-Documenting

GET /help returns a one-page operating manual the agent loads at runtime.

Single Static Binary

Go, zero external dependencies, deploys as one file.

Zero Config Defaults

Runs out of the box. Config: defaults < file < env < flags.

API Reference

MethodEndpointDescription
POST/formatPretty-print JSON (?indent=N)
POST/minifyCompact JSON (no whitespace)
POST/validateCheck if JSON is valid
POST/queryExtract value by dot-path (?path=user.name)
POST/extractExtract specific keys (?keys=name,age)
POST/flattenFlatten nested objects (dot notation)
POST/unflattenUnflatten dot-keys into nested objects
POST/mergeMerge multiple JSON objects
POST/diffDiff two JSON objects
POST/sortSort array elements
POST/filterFilter array by key=value (?cond=key=value)
POST/transformApply pipe-separated operations (?ops=keys|sort)
POST/analyzeGet JSON statistics
GET/helpOperating manual for agents

Transform Operations

Operations are |-separated. Supported: keys, values, sort, reverse, unique, flatten, minify, pretty, lowercase, uppercase

curl -X POST "localhost:8484/transform?ops=keys|sort" -d '{"c":3,"a":1,"b":2}'
# ["a","b","c"]

curl -X POST "localhost:8484/transform?ops=sort|reverse" -d '[1,2,3]'
# [3,2,1]
